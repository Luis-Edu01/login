# 🔐 Projeto Tela de Login - Responsivo com HTML e CSS

Este projeto é uma atividade prática desenvolvida como parte do curso de **HTML e CSS** do professor **Gustavo Guanabara**, disponível gratuitamente na plataforma Curso em Vídeo.

O objetivo principal foi criar uma tela de login com layout moderno e responsivo, utilizando boas práticas de semântica, estilização e responsividade com **Media Queries**.

---

## 🧰 Tecnologias utilizadas

* **HTML5** – Estruturação semântica da página
* **CSS3** – Estilização, variáveis, gradientes, fontes e animações
* **Media Queries** – Responsividade para diferentes tamanhos de tela
* **Google Fonts (Material Symbols)** – Ícones no formulário

---

## 📱 Responsividade

A página se adapta de acordo com o tamanho da tela:

* Em **telas pequenas**, o login aparece em coluna única.
* Em **telas médias e grandes**, a imagem e o formulário se reposicionam lado a lado com comportamento fluido.
